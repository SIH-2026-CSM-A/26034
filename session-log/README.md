# session-log

**Owner:** @Abhiram-0910 (directory); one file per person, owned by that person

One file per person: `session-log/<your-name>.md`. Append to yours; never edit someone
else's, and never create a shared `SESSION-LOG.md` at the repo root — ten people writing
to one file is a merge conflict on every PR.

Record what you changed and anything the next person needs that the diff does not say:
a decision and why, something that turned out not to work, an environment quirk. Name
the tool if an agent did the work — Claude Code, Antigravity and OpenCode are all in use
here and it matters who to ask.
